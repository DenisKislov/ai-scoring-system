# Фронтенд системы скоринга

React-приложение для загрузки вакансий и резюме, запуска скоринга и просмотра рейтинга кандидатов. Запросы отправляются в FastAPI на `http://localhost:8000`.

## Локальный запуск

Из каталога `frontend`:

```bash
npm ci
npm start
```

Приложение откроется на `http://localhost:3000`. Для работы с данными запустите API и MongoDB по инструкции в корневом `README.md`.

## Проверка и сборка

```bash
npm test -- --watchAll=false
npm run build
```

Готовые статические файлы появятся в `frontend/build`. Запуск всего проекта через Docker Compose описан в корневом `README.md`.
