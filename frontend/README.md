# Веб-интерфейс

React-приложение: создание вакансии, загрузка PDF/TXT-резюме, выбор критических навыков, рейтинг с объяснением Score, исходный текст с подсветкой и история решений HR. Панели оценочных метрик на сайте нет; качество измеряется отдельными бенчмарками.

## Запуск

Весь проект из корня:

```bash
docker compose up -d --build --wait
```

Интерфейс — http://localhost:3000, Swagger — http://localhost:8000/docs. Nginx перенаправляет `/api` в backend.

Локальная разработка из `frontend` (Node.js 22, API и MongoDB запущены отдельно):

```bash
npm ci
npm start
```

Адрес API задаётся `REACT_APP_API_URL` при сборке. В Docker используется `/api`; локально — порт 8000 того же хоста. Изменение переменной требует пересборки. Внешние импорты скрыты по умолчанию.

## Проверка

```bash
CI=true npm test -- --watchAll=false --runInBand
npm run build
```

Статические файлы записываются в `build/`. Для PowerShell переменная `CI` задаётся отдельно. Оформление использует белый, графитовый и синий цвета; на узком экране колонки переходят в последовательные блоки.

Готовые синтетические PDF для загрузки находятся в `data/pmi_acceptance_release_2026-11-18/`. [Руководство пользователя](../docs/USER_GUIDE.md), [методика измерения качества](../docs/ACCEPTANCE_DATASET.md), [отчёт](../reports/pmi_release_2026-11-18/README.md).
