# Фронтенд системы скоринга

React-приложение для загрузки вакансий и резюме, запуска скоринга и просмотра рейтинга кандидатов. Запросы отправляются в FastAPI на `http://localhost:8000`.

## Локальный запуск

Из каталога `frontend`:

```bash
npm ci
npm start
```

Приложение откроется на `http://localhost:3000`. Для работы с данными запустите API и MongoDB по инструкции в корневом `README.md`.

## Проверка и сборка

```bash
npm test -- --watchAll=false
npm run build
```

Готовые статические файлы появятся в `frontend/build`. Запуск всего проекта через Docker Compose описан в корневом `README.md`.

Адрес API задаётся `REACT_APP_API_URL` при сборке; Docker использует `/api` и Nginx proxy. Внешние импорты скрыты по умолчанию, для локального включения нужен `REACT_APP_ENABLE_EXTERNAL_IMPORTS=true` при сборке и разрешение импорта на backend. Форма вакансии, история HR, вклад компонентов и JSON описаны в `../docs/USER_GUIDE.md`.

Оформление: белый, графитовый и синий цвета; адаптивная компоновка, нейтральные статусы и выделение выбранных элементов. Загрузка и создание вакансий находятся слева, параметры и рейтинг — справа; на узком экране блоки идут последовательно.
