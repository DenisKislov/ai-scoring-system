- [x] **Новый PMI-прогон с включённым NER** (L). Fingerprint алгоритма
  изменился (`ner_skills_enabled: true`); зафиксированные протоколы

  Независимая проверка заказчиком и формальная приёмка остаются отдельными действиями.
- [x] **Починить методологию порога фильтра** (M). Порог
  (`scorer/auto_threshold.py`, `api/threshold_service.py`) считается по
  ground-truth аннотациям, а фронт фильтрует по извлечённым навыкам —
  порог систематически строгий; min-of-max ломается от одного outlier'а.
  Считать тем же пайплайном (извлечение → overlap) на целевом датасете,
  робастная статистика (перцентиль вместо min). Приёмка: порог,
  посчитанный на `data/benchmark`, не прячет top-1 кандидата ни одной
  вакансии.
- [x] **`fontTools` в `requirements.lock`** (S). Нужен `pmi/dataset.py`
  (генерация PDF) и тестам `tests/pmi`; сейчас свежее окружение по README
  роняет 2 теста. Альтернатива — зафиксировать в RUNBOOK `pip install
  fontTools` (сделано как workaround, но lock должен быть полным).
