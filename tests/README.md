# Проверки и бенчмарки

Запуск из корня проекта:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python tests/eval_synthetic.py
.venv/bin/python scripts/benchmark_synthetic.py
```

`tests/eval_synthetic.py` проверяет прежний регрессионный ориентир NDCG@10 ≥ 0,80 на том же
многосидовом расчёте, который используется в
`scripts/benchmark_synthetic.py`. Бенчмарк сохраняет агрегированные
результаты в `reports/synthetic_benchmark.md` и `.json` и выводит
Precision@10, Recall@10, MAP, MRR, NDCG@10 и Spearman. Порог бинарной
релевантности — 0,65; NDCG использует непрерывную метку.

`test_synthetic_realism.py` проверяет шесть направлений, связность стека,
воспроизводимость генерации и вычисление метки из скрытого профиля.
`test_metrics.py` проверяет расчёт метрик извлечения навыков по категориям.
`test_experience.py` проверяет парсер опыта координатора, `test_matching_families.py`
— сопоставление групп навыков, `test_similarity.py` — TF-IDF и стабильность
Score при пулах из 10 и 200 резюме. API-тесты проверяют передачу критических
навыков и отсутствие подсказок скрытого профиля при генерации.

Для проверки показателей по ПМИ нужен её отдельный протокол: критерий
NDCG@10 ≥ 0,90, порог бинарной релевантности 0,1 и остальные проверки.
Регрессионная проверка 0,80 не означает прохождение ПМИ.

`integration_demo.py` демонстрирует путь MongoDB → скорер → MongoDB и требует
запущенной MongoDB. Его следует запускать отдельно. Синтетические метрики
показывают качество только на контролируемом наборе, а не на реальных наймах.

## ПМИ Т1-1 v1

`tests/pmi/test_acceptance.py` связывает автоматические проверки с А-1—А-20. Они используют FastAPI TestClient и mongomock, поэтому не требуют рабочей БД и не очищают данные пользователя. Для реального Docker-стенда, остановки MongoDB, перезапуска всех контейнеров и нагрузки 10×200 выполните `python -m pmi live`. Полный запуск и протокол: `python -m pmi run --live`, `docs/PMI.md`.

Приёмочные численные пороги не понижаются до прежнего регрессионного 0.80. Недостигнутые критерии и ручные проверки остаются видны в отчёте.
