# Испытания по ПМИ

Технические проверки А-1–А-20 представлены модульными тестами, проверками API и отдельным Docker-прогоном. Результаты текущей поставки — `reports/pmi_release_2026-11-18`; данные — `data/pmi_acceptance_release_2026-11-18`.

## Повторение

Из корня проекта, Python 3.13 на Linux/macOS; для Python-драйвера в Windows используйте WSL. Сам сайт запускается в Docker Desktop без установки Python на хосте.

```bash
python -m pip install -r requirements.lock -r tests/requirements.txt
python -m pmi verify --dataset data/pmi_acceptance_release_2026-11-18
python -m pmi quality --dataset data/pmi_acceptance_release_2026-11-18 --output reports/reproduction
python -m pmi live --dataset data/pmi_acceptance_release_2026-11-18 --output reports/reproduction
```

Готовые PDF уже включены в репозиторий. Отсутствующие файлы восстанавливаются только при совпадении с замороженными хэшами. Для `live` нужен Docker и свободные порты 18000/13000. `--cached-images` использует уже скачанный MongoDB без обращения к реестру. Создаётся отдельный Compose-проект и отдельная база; после испытаний удаляются только его контейнеры и тома. `--keep` оставляет этот стенд для ручной проверки.

Дополнительные этапы с теми же `--dataset` и `--output`: `performance`, `audit`, `report`. `run --live` объединяет качество, локальную производительность, аудит, pytest и контейнерные сценарии. Общий код завершения остаётся ненулевым до выполнения условий формальной приёмки; технический результат смотрите в `live.json`, численные критерии — в `quality_api.json`.

## Метрики

| Показатель, среднее по вакансиям | Минимум |
|---|---:|
| NDCG@10 | 0,90 |
| Precision@5 | 0,90 |
| Precision@10 | 0,90 |
| Recall@10 | 0,15 |
| Spearman | 0,80 |

Бинарная релевантность — не менее 0,1. Recall усредняется по вакансиям хотя бы с одним подходящим резюме. NDCG использует линейный gain. P/R/F1 навыков рассчитываются по категориям с TP/FP/FN; отдельного минимума для них ПМИ не задаёт. MAP и MRR сохраняются дополнительно.

Упрощённая формула (5) ПМИ со средними рангами при связях отличается от обычной корреляции рангов. Отчёт содержит оба значения: `spearman` — буквальная формула ПМИ, `spearman_tie_corrected` — стандартная корреляция. На текущем наборе оба значения превышают 0,8.

Состав и влияние редкой вакансии на средние значения раскрыты в [методике](ACCEPTANCE_DATASET.md). Средний критерий не означает прохождение каждой вакансии отдельно. Навыки и стаж берутся из результата парсера; эталонные поля нужны только для оценки.

## Фиксация

Manifest содержит SHA-256 входных файлов и исходников, конфигурацию, модель и версии зависимостей. Изменение замороженных входов останавливает `quality` и `live`. Для новых исходников нужен отдельный протокол:

```bash
python -m pmi build --dataset data/pmi_new_protocol --dataset-style acceptance --output reports/pmi_new_protocol
python -m pmi run --live --dataset data/pmi_new_protocol --output reports/pmi_new_protocol
```

Справочник для А-20 изменяется в отдельной копии конфигурации стенда; рабочие настройки не затрагиваются. Исторические manifests не перезаписываются под новую версию.

## Техническое покрытие

| Пункты | Проверка |
|---|---|
| А-1–А-2 | Формы и загрузка PDF/TXT, пакеты, оригиналы и SHA-256, нормализация алиасов |
| А-3–А-5 | Конфигурация, повторяемость, порядок и уникальность рейтингов, объяснение и исходный текст |
| А-6–А-8 | История HR, OpenAPI, валидация, журнал и каскадное удаление |
| А-9–А-12 | Качество всех пар, нулевые и сильные пары, критические навыки и неизменность пары при смене пула |
| А-13–А-16 | Ошибки файлов, остановка БД, восстановление томов, HTTP-тайминги |
| А-17–А-18 | Исключение персональных признаков; поиск контактов и секретов и отдельная экспертиза |
| А-19–А-20 | Четыре контейнера, HTTP-доставка интерфейса, расширение словаря без изменения кода |

TestClient и mongomock не заменяют контейнерное измерение. HTTP-доступность интерфейса не подтверждает внешний вид в браузерах. А-18 не объявляется полностью пройденным по одному автоматическому поиску.

## Ручные условия

[Лист приёмки](PMI_MANUAL.md): независимое развёртывание, версии браузеров, внешний вид и Swagger, комплект документов, происхождение данных, согласованная версия выпуска и акт. Точное соответствие авторских PDF официальному экспорту hh.ru подлежит подтверждению. Подписи и решения комиссии не генерируются автоматически.

Замечание к истории Git сохранено по решению пользователя: `reports/pmi/known_exceptions.md`. Численные результаты текущего синтетического замера не устраняют это замечание. Формальная приёмка не оформлена.
