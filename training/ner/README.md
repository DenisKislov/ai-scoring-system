# Обучение модели навыков

Рабочее извлечение находится в `scorer/`. Этот каталог содержит инструменты обучения и оценки; их запуск не заменяет модель основного сайта.

Для обучения на неизменных JSON презентации используйте `superjob_cv.py`. Он разделяет 10 вакансий и 194 резюме на пять частей, отдельно выбирает эпоху внутри каждой обучающей части и сохраняет прогноз каждого внешнего документа. Разметка сущностей строится автоматически из существующих навыков и найденных в тексте упоминаний; независимая экспертная разметка этим не создаётся.

```bash
python -m pip install -r requirements.lock -r training/ner/requirements-training.txt
PYTHONHASHSEED=20261118 python -m training.ner.superjob_cv \
  --output-dir training/ner/out/superjob_cv_repeat \
  --report-dir reports/superjob_cv_repeat --workers 2 --epochs 24
```

Команда требует нового выходного каталога и не меняет входные JSON. После пяти проверок она обучает финальную модель на всех документах; число эпох определяется внутренними проверками. Контактные строки из сериализованного словаря удаляются с проверкой неизменности предсказаний.

У отчёта три различных результата: OOF-извлечение каждого документа, рейтинг полного пула из прогнозов пяти моделей и показатели финальной модели на обучающих данных. Дополнительно сохраняются рейтинги по меньшим внешним пулам каждой части. Эти режимы нельзя выдавать за один независимый замер одной модели на 194 новых резюме.

Читаемая таблица формируется после обучения:

```bash
python -m training.ner.cv_report reports/superjob_cv_repeat
```

Для подключения финального артефакта сначала нужны проверка регрессий и новый протокол соответствующей версии. Полные пользовательские PDF и подготовленные DocBin других корпусов данный сценарий не читает.

## Текущая поставка

Рабочая модель использует spaCy `tok2vec` + `ner` с меткой `Skill`; она объединяется со словарём в `scorer/skills.py`. Модели экспериментов из этого каталога автоматически в сайт не подключаются. [Текущий PDF-замер](../../reports/pmi_release_2026-11-18/README.md) использует готовую рабочую модель и отдельный [синтетический набор](../../data/pmi_acceptance_release_2026-11-18/); обучение на нём не выполнялось.
