# Наборы данных

## Синтетический PDF-набор

`pmi_acceptance_release_2026-11-18/` включён в репозиторий целиком: 10 вакансий, 200 резюме, пять направлений и 2000 размеченных пар. Для его проверки внешние данные не требуются.

| Файл или каталог | Содержание |
|---|---|
| `dataset.json` | Тексты, эталонные навыки, стаж, критические требования и истинная релевантность пар |
| `resumes/` | 200 машиночитаемых синтетических PDF |
| `vacancies/` | 10 синтетических PDF вакансий |
| `controls/` | Алиасы, критические навыки, персональные варианты, повреждённые и неподдерживаемые файлы |
| `manifest.json` | Хэши документов, разметки, настроек, модели и исходников |

Все кандидатские сведения вымышлены. Набор используется для полного пути PDF → парсер → база → скорер → рейтинг. При расчёте передаются извлечённые навыки и стаж; эталон используется только для оценки. Разметка задана генератором как взвешенное покрытие способностей.

```bash
python -m pmi verify --dataset data/pmi_acceptance_release_2026-11-18
python -m pmi quality --dataset data/pmi_acceptance_release_2026-11-18 --output reports/reproduction
```

[Методика и ограничения](../docs/ACCEPTANCE_DATASET.md), [текущий отчёт](../reports/pmi_release_2026-11-18/README.md). Средние метрики зависят от состава набора; результаты каждой вакансии опубликованы рядом со средним.

## JSON-бенчмарк

`benchmark/superjob_dataset.json` и `benchmark/dataset_resume.json` — опубликованные копии прежнего набора: 10 вакансий и 194 резюме. Это отдельный эксперимент, не текущие PDF-данные.

```bash
python scripts/benchmark_real_data.py --dataset-dir data/benchmark --ranking-inputs annotated
python scripts/benchmark_real_data.py --dataset-dir data/benchmark --ranking-inputs extracted
```

`annotated` подаёт скореру готовые навыки и проверяет ранжирование; `extracted` извлекает навыки из JSON-текстов. По умолчанию выбраны первые 10 вакансий, `annotated` и порог 0,1. Ни один режим не включает загрузку PDF. В JSON-разметке встречаются навыки, не подтверждённые сокращённым текстом; независимой экспертной оценки пригодности всех пар нет.

## Локальные исходники и другие генераторы

`superjob_dataset.json`, `dataset_resume.json`, исходные `resumes/` и `vacancies/` — локальные входы, не входят в поставку. Канонические CSV — `ground_truth_resumes.csv` и `ground_truth_vacancies.csv`; они относятся к своим составам документов и не подменяют разметку нового набора.

`synthetic.py`, `synthetic_roles.json` и `profiles.py` обслуживают демонстрационный генератор интерфейса и отдельную диагностику шести ИТ-профилей. Кнопка генерации в интерфейсе не загружает опубликованный набор ПМИ. Режимы `pmi` `legacy`, `hh` и `it` сохраняют воспроизводимость прежних синтетических протоколов; текущий генератор — `acceptance`.

`DATA_ENGINEER.md` — исторический отчёт о первой версии генератора. Прежние manifests и отчёты сохраняют хэши своих версий; новые исходники проверяются отдельным протоколом.
