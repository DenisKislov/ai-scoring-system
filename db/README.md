# Хранение данных и построение профиля

`mongo.py` обеспечивает MongoDB CRUD, сохранение оригиналов, рейтингов и решений HR. `builders.py` формирует вход скорера, извлекает должность и стаж; навыки получает через `scorer.extract_skills` (словарь + spaCy NER).

| Параметр | По умолчанию |
|---|---|
| `MONGO_URI` | `mongodb://mongo:27017` |
| `MONGO_DB` | `gb_parse` |
| `MONGO_TIMEOUT_MS` | 2000 мс |

Для локального API адрес MongoDB задаётся явно: `mongodb://localhost:27017`. Основные коллекции: `hh`, `hh_resumes`, `hh_scores`, `hh_feedback`; имена определены константами в `mongo.py`.

## Документы и рейтинги

Оригинальные байты PDF/TXT хранятся вместе с SHA-256. Для загруженного резюме `resume_text` возвращает сохранённый `_raw_text`; для структурированного документа собирает доступные поля. `vacancy_text` объединяет название, описание, навыки и теги.

`parse_raw_text_to_resume` вызывает извлечение навыков и правила стажа. `experience_years` использует сохранённое числовое значение, затем текстовые поля. Неизвестный стаж хранится как `null`; он не равен нулю.

Рейтинги имеют уникальный ключ `(vacancy_id, resume_id)` и сохраняются без дублей. Выдача БД и сервиса упорядочена по целому Score, наличию и убыванию стажа, затем ID. Сохраняются компоненты, объяснение, дата, веса и fingerprint. Решения `yes/no` содержат последнее значение и историю событий. Удаление документа каскадно удаляет связанные оценки, историю и оригинал.

## Демонстрационные данные

```bash
python -m db.seed --vacancies 5 --resumes 20 --seed 42
```

Команда добавляет демонстрационные данные в выбранную базу; навыки извлекаются из текста, скрытая разметка не подставляется в расчёт. `--clear` удаляет синтетику и все рейтинги этой базы, поэтому применяется только к выделенной демонстрационной БД.

Готовый [PDF-набор](../data/pmi_acceptance_release_2026-11-18/) проверяется отдельным драйвером `python -m pmi live`, который создаёт собственную MongoDB и не использует рабочую базу. Методика и результаты — [в документации](../docs/ACCEPTANCE_DATASET.md).
