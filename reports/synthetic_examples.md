## Вакансия

Вакансия: Python-разработчик
Команда развивает действующий сервис и открыла новую позицию. Сервис обрабатывает обращения клиентов и передаёт данные в несколько внутренних систем. Работа включает новые задачи и сопровождение действующей системы; решения обсуждаются с соседними командами.

Задачи:
- развивать API для личного кабинета;
- ускорять обработку фоновых задач;
- обсуждать решения с разработчиками, аналитиками и владельцем продукта;
- оценивать изменения перед релизом и помогать с их сопровождением.

Требования:
- коммерческий опыт от 4 лет;
- уверенная работа с FastAPI, Python;
- практический опыт: Redis, Kafka; также PostgreSQL, SQL.
Будет плюсом опыт с Prometheus, REST API, pytest.

Условия: гибридный график, задачи с понятным владельцем и регулярное код-ревью. При отклике полезно коротко описать проект, за который отвечали лично.
