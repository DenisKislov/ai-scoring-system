# Отчёты до интеграции версии куратора

Эти файлы перенесены без изменения содержимого 20 октября 2026 года. Они относятся к прежнему скореру и прежнему состоянию корпуса и сохранены для истории. Их результаты и прежние упоминания требований ТЗ не являются результатами проверки текущей версии и не подтверждают приёмку по ПМИ.
