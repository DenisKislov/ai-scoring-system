| Контрольный корпус | Те же 10 вакансий, 194 резюме и 1940 пар из `data/benchmark`, что использованы в презентации. Тексты и expected_skills не изменены |
| Режим | Навыки извлекаются из текста; эталонные навыки не передаются продуктивному скореру |
| Формулы | Сохранены nDCG с линейным gain, Precision@5/10, Recall@10 и scipy Spearman исходного бенчмарка. Бинарный порог релевантности 0.1 |
| Цели | nDCG@10≥0.9; P@5≥0.9; P@10≥0.9; R@10≥0.15; Spearman≥0.8. Это применение численных порогов ПМИ к реальному диагностическому набору, а не формальное испытание по п. 5.3 ПМИ |

| Разработка ранжирования | 101 другая локальная вакансия: 75 для подготовки словаря и фиксированного TF-IDF, 26 для выбора настроек. Кандидатный пул общий, поэтому это разделение по вакансиям, а не полностью независимая выборка людей |
| Проверенные настройки | 420 комбинаций: старое/расширенное извлечение, частичный зачёт семейств, веса, фиксированный TF-IDF по словам/символам, обнуление оценки при отсутствии совпадений. Настройка выбиралась по другим 26 вакансиям |
| Обучение NER | Два кандидата: новая Skill-модель и дообучение официальной ru_core_news_sm 3.8.0. Автоматическая разметка; 172 обучающих и 43 валидационных документа, 536/122 текстовых фрагмента |
| Исключение пересечений | По 5-граммному Jaccard≥0.4 исключены 104 подготовленных документа. Дополнительный containment-аудит нашёл ещё 5 подозрительных частичных совпадений; независимость обучения не доказана |
| Файлы PDF пользователя | Исходные `data/resumes` и `data/vacancies` не открывались. Использованы уже подготовленные DocBin и локальные JSON |

| Вывод | Пояснение |
|---|---|
| Цель пока не достигнута | Обучение новых моделей и подбор настроек на других вакансиях не обеспечили все требуемые численные значения на неизменном реальном наборе |
| Контроль регрессий | Лучшая по валидации настройка повысила nDCG на контрольном наборе, но снизила Spearman. Новая Skill-модель слегка улучшила ранжирование, но ухудшила F1 извлечения резюме. Поэтому они не заменяют основную версию |
| Ограничение текстовых выдержек | Часть expected_skills отсутствует в доступном тексте. Навыки, отсутствующие в тексте, нельзя считать фактически извлечёнными только потому, что они типичны для профессии. Это не доказывает математическую невозможность достичь целевых рангов; оно ограничивает интерпретацию результата |
| Оценка правдоподобия | Высокий F1 NER на автоматически размеченных фрагментах не означает высокий nDCG или качество независимого распознавания реальных резюме. Показатели не заменяются результатами режима annotated |
| Следующее решение | Уточнить, фиксируются ли именно опубликованные сокращённые JSON или можно извлечь полные тексты тех же документов без изменения состава и разметки. Полные тексты изменят вход бенчмарка, и это нужно явно отразить в сравнении |
| Дальнейшая работа на строго тех же JSON | Нужны дополнительные независимые обучающие примеры и отдельная проверка качества разметки. Достижение всех порогов заранее не обещается. Этот отчёт не подтверждает формальную приёмку |
| Артефакты | candidate_results.json; development_ranking_search.json; ner_validation.json; scratch_history.json; transfer_history.json; манифесты обучения. Исходные тексты и обученные экспериментальные модели остались в отдельной локальной рабочей копии и не публиковались |
