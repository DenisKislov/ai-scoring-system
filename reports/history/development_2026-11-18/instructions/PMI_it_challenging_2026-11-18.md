# Диагностика смежных ИТ-профилей

Новый набор: `data/pmi_it_challenging_2026-11-18`. Результаты: `reports/pmi_it_challenging_2026-11-18`. Это отдельный синтетический стресс-тест с пятью смежными специальностями, десятью вакансиями и 200 PDF-резюме. Прежние данные и результаты сохранены.

Сценарии усложнения выбраны после просмотра прежнего простого набора. Поэтому новый результат не является независимой слепой валидацией. Seed, документы, разметка, модель и настройки зафиксированы до первого замера; отбор удачного seed или исключение неудобных документов не выполнялись.

Повторение из корня проекта в окружении Python 3.13 с зависимостями `requirements.lock` и `tests/requirements.txt`:

```bash
python -m pmi verify --dataset data/pmi_it_challenging_2026-11-18
python -m pmi quality --dataset data/pmi_it_challenging_2026-11-18 --output reports/pmi_it_challenging_2026-11-18/reproduction
python -m pmi live --dataset data/pmi_it_challenging_2026-11-18 --output reports/pmi_it_challenging_2026-11-18/reproduction --cached-images
```

`quality` и `live` восстанавливают отсутствующие PDF по замороженному manifest с побайтовой проверкой. Для `live` нужен работающий Docker и уже скачанный `mongo:8` для linux/amd64. Если образа нет, уберите `--cached-images`, чтобы разрешить обычную загрузку. Создаётся отдельный Compose-проект; после испытаний удаляются только его контейнеры и тома. Основная база не используется. Порты временного стенда: 18000 и 13000.

Ненулевой код завершения ожидаем: на этом наборе не выполнены Recall@10 и А-10. Это записанные результаты испытания, а не ошибка запуска. Полная формальная приёмка ПМИ не оформляется автоматически.

Для нового эксперимента с этим генератором используйте новый путь:

```bash
python -m pmi build --dataset data/pmi_it_new_protocol --dataset-style it --output reports/pmi_it_new_protocol
```

Правило релевантности сохранено от прежней синтетики: прямое взвешенное покрытие скрытых навыков, критический навык имеет вес 2, остальные — 1. При пороге 0,1 и большом числе общих навыков релевантными становятся 149–177 резюме на вакансию. Даже идеальный рейтинг тогда даёт Recall@10 в среднем не выше 0,06099; минимум 0,15 на таком составе недостижим. Изменять порог, состав или разметку после замера для устранения этого результата нельзя считать тем же испытанием.

Score, его веса, рабочая spaCy-модель и словарь не менялись. PDF имеют авторскую вёрстку с разделами, похожими на hh.ru; они не экспортированы сервисом. Набор не является исходным SuperJob и не характеризует весь рынок труда.

Их предыдущие версии сохранены в `reports/pmi_it_challenging_2026-11-18/previous_harness`; совпадение с прежними исходными хэшами проверено в `verification.json`. Исторические manifests не перезаписываются под новые исходники.
