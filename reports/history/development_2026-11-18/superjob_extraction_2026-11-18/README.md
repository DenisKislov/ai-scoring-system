# Качество извлечения навыков на реальном локальном корпусе — 18.11.2026

| Условия | Значение |
|---|---|
| Версия | `13046f82`, `spacy-pmi-1.1.0` |
| Данные | Локальные `data/dataset_resume.json`: 194 резюме; `data/superjob_dataset.json`: 111 вакансий. Это полный имеющийся реальный корпус, а не синтетический набор ПМИ |
| Состав | 98 структурированных резюме и 85 вакансий SuperJob; 96 резюме и 26 вакансий с ранее сохранёнными полными текстами PDF |
| Эталон | Поле `expected_skills`; 3940 размеченных навыков резюме, 1803 навыка вакансий после канонизации. У одного резюме эталонный список пуст, извлекатель также не выдал навыков |
| Вход извлекателя | Только профессиональный текст из существующих JSON, без передачи `expected_skills` |
| Что сравнивается | Канонические наборы навыков каждого документа, без учёта регистра. Семейства навыков из скоринга не заменяют точное совпадение |
| Чего метрики не измеряют | Качество ранжирования, опыт работы, пригодность кандидатов, извлечение текста из новых PDF |
| Исходные папки PDF | Не читались; повторная загрузка документов и обучение не выполнялись |
| Свидетельства | [extraction.json](extraction.json): SHA-256 входов, fingerprint обеих конфигураций, результаты по каждому документу без текстов и исходных идентификаторов |

| Интерпретация | Вывод |
|---|---|
| Польза spaCy для резюме | Дополнительно найдено 441 размеченное вхождение навыка по документам; ещё 253 находки отсутствуют в эталонных списках. F1 вырос с 0.5439 до 0.6122, Precision немного снизился |
| Польза spaCy для вакансий | Дополнительно найдено 357 размеченных вхождений, 33 дополнительные находки отсутствуют в эталоне. F1 вырос с 0.3443 до 0.5622; Precision также вырос |
| Общая оценка | spaCy улучшает извлечение, но полнота остаётся ограниченной: найдено 57.36% размеченных навыков резюме и 41.49% вакансий. Эти значения нельзя описывать как отличное качество извлечения |
| Влияние полноты текста | На полных PDF-текстах Recall составляет 83.42% для резюме и 79.48% для вакансий; на структурированных выдержках — 39.92% и 31.17%. Это разные подвыборки, поэтому разницу нельзя целиком приписать одному фактору |

| Разбор расхождений | Наблюдение |
|---|---|
| Пропущенные навыки без найденной текстовой формы | Среди FN не найдено совпадения с диагностическим шаблоном для 1244 из 1680 навыков резюме и 479 из 1055 навыков вакансий. Это признак возможной неполноты текстов/алиасов, а не доказательство отсутствия смысла. Проверены короткие профессиональные фрагменты отдельных ошибок |
| Навык в тексте есть, но основной извлекатель пропустил | Диагностический шаблон эталонного навыка сработал для 436 FN резюме и 576 FN вакансий. Есть пробелы словаря и пропуски модели, например `Aiogram`, `Gunicorn`, `Docker Compose`, `дашборды` |
| Разные написания одного навыка | `Power Shell` извлекается как отдельная строка, тогда как эталон ожидает `PowerShell`. Нужна согласованная канонизация вариантов |
| Разные словоформы | Модель иногда возвращает фразы в форме текста, например `алгоритмов`, `прогнозирования`, а эталон содержит другие формы |
| Частично неверное разбиение | В одном проверенном примере текст `Java Script` дал дополнительный `Java`: это требует уточнения распознавания многословных написаний |
| Неполная разметка дополнительных навыков | В других проверенных примерах `Java` прямо присутствует в профессиональном тексте, но отсутствует в `expected_skills`. Такие FP требуют проверки эталона; автоматически считать их галлюцинациями нельзя |
| Частые расхождения | Часто пропущены `PostgreSQL`, `Git`, `Linux`, `TypeScript`. Частые дополнительные находки относительно эталона: `IT`, `SQL`, `Java`, `API`. Списки и количества — в extraction.json |
| Диагностика | [reference_visibility.json](reference_visibility.json). Шаблоны, построенные с использованием эталонных названий, служат только поиску причин FN. Их результаты не подставляются в продуктивное извлечение и не улучшают приведённые метрики |

| Ограничения вывода | Пояснение |
|---|---|
| Независимость | Словарь ранее настраивался по этому корпусу, часть PDF-текстов пересекается с обучением spaCy. Это диагностический замер текущей версии, не независимый слепой тест |
| Качество эталона | Независимая повторная экспертная разметка всех документов не выполнена. FP/FN здесь обозначают расхождения с имеющимися метками |
| Сопоставление с прошлым отчётом | Ранее опубликованный набор содержит только 10 вакансий. В текущем замере использованы все 111 локальных вакансий; число и состав запросов другие. У резюме локальные тексты немного отличаются от опубликованных обезличенных выдержек |
| Строго SuperJob без добавленных PDF | Отдельные результаты 98 резюме и 85 вакансий приведены выше; их F1 со spaCy — 0.5321 и 0.4633 |
