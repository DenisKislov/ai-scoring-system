## Бенчмарки

| Метрика | Контрольный набор ПМИ | Более шумная синтетика, 6 ИТ-профилей |
|---|---:|---:|
| Число пар | 2000 | 1080 |
| Precision@10 | 1.000 | 1.000 |
| Recall@10 | 0.253 | 0.346 |
| MAP | 1.000 | 0.995 |
| MRR | 1.000 | 1.000 |
| NDCG@10 | 0.996 | 0.913 |
| Spearman, с поправкой на связанные ранги | 0.99975 | 0.785 |

В контрольном протоколе ПМИ дополнительно вычисляется буквальная упрощённая формула Spearman из документа: 0.99988. На 1604 парах с нулевой релевантностью нарушений А-10 нет. Precision@5 = 1.000.

Для более шумной синтетики предыдущие NDCG/Spearman были 0.908/0.774; теперь 0.913/0.785. **Spearman всё ещё ниже 0.8** на этом диагностическом наборе. Положительных пар при пороге 0.1 очень много (1042/1080), поэтому Precision@10 = 1.000 сам по себе не означает идеального ранжирования.
