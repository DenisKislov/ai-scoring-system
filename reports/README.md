## Диагностика и история

- [Извлечение на SuperJob](history/development_2026-11-18/superjob_extraction_2026-11-18/README.md).
- [Раздельная проверка обучения NER](history/development_2026-11-18/superjob_cv_2026-11-18/README.md).
- [Предыдущий PDF-протокол](history/development_2026-11-18/pmi_acceptance_2026-11-18/README.md).

`spacy_integration_2026-11-18/` — исходная интеграция рабочей модели; `ner_gate/` — история её гейта. Экспериментальные модели не заменяют рабочую автоматически.

`baseline_pmi_2026-10-27/`, `audit-2026-10-26/`, `pmi/` и `history/pre_integration/` относятся к своим версиям, составам и датам. Их числа не переносятся на текущую систему автоматически. Исторические подписанные материалы сохранены без изменения результатов.

`pmi/known_exceptions.md` фиксирует решение сохранить историю Git с замечанием к А-18. Успешный новый синтетический замер не отменяет это замечание.
