# Дополнительная диагностика реалистичной синтетики

На текущем алгоритме выполнен прежний генератор шести ИТ-профилей: 36 вакансий, по 30 резюме, 1080 пар, три seed. При пороге 0.1 получены Precision@10 1.000, Recall@10 0.346, MAP 0.994, MRR 1.000, NDCG@10 0.908, стандартная корреляция Спирмена 0.774.

Если применить к этой диагностике минимум ПМИ для корреляции 0.8, он не достигнут. Результат сохранён без снижения порога и без подбора весов/меток по этому прогону. Контролируемый приёмочный набор по пяти разным направлениям заметно проще и имеет другую процедуру разметки; его высокие показатели нельзя переносить на эту диагностику или реальные резюме.

## Причины и предложения

У реалистичного генератора релевантность зависит от скрытых, иногда не упомянутых навыков, соответствия роли и опыта. Реализация скорера использует извлечённые из текста навыки и TF-IDF, а опыт — только при равенстве Score. В текстах могут быть упомянуты учебные знания без профессионального применения. Широкие семейства технологий координатора дополнительно дают частичные ложные совпадения.

Для дальнейшего улучшения нужны отдельная выборка для доработки словаря, направленные вместо широких симметричных соответствий технологий и распознавание контекста владения навыком. Оценку следует повторить на заранее замороженной проверочной выборке, с согласованным определением релевантности и независимой экспертной разметкой реальных пар. Источник чисел: `realistic_diagnostic/synthetic_benchmark.json`.
