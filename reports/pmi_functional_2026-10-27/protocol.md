## Ограничения

- Проверена текущая рабочая копия с незакоммиченными изменениями, а не утверждённый релизный тег.
- Тестовый набор синтетический. Пользовательские каталоги data/resumes и data/vacancies не открывались и не входят в эти испытания.
- Замеры относятся к указанному стенду и простым PDF с текстовым слоем. Сборка контейнеров не входит в 6,112 с. Минимальная целевая машина не проверена.
- А-18: регулярные выражения не доказывают отсутствие всех ПДн. Локальные исходные JSON и пользовательские PDF исключены из текущего аудита распространяемых исходников; их публикация не проверена. Согласованное историческое замечание не закрывается этим автоматическим прогоном.
- А-19: macOS ARM64 с Linux amd64 контейнерами не подтверждает запуск на целевых физических Linux/Windows x86-64 и в двух целевых браузерах.
- А-9: результаты ранжирования отдельно в reports/curator_pmi_2026-10-27/. Использованы размеченные навыки; это не сквозная оценка извлечения из PDF и не полный протокол К1—К6.
- Формальная приёмка, подписи комиссии и проверка заказчиком не выполнены.

## Воспроизведение

```bash
python -m pmi build --dataset /private/tmp/pmi-functional-repeat --output reports/pmi-functional-repeat
python -m pmi verify --dataset /private/tmp/pmi-functional-repeat --output reports/pmi-functional-repeat
python -m pmi live --dataset /private/tmp/pmi-functional-repeat --output reports/pmi-functional-repeat
```

Новый запуск создаёт отдельный протокол. Команда live/report может завершиться ненулевым кодом до формальной приёмки. Интерфейс и Swagger проверяются отдельно по docs/PMI_MANUAL.md. Для А-10 используется проверка всех пар из pmi.quality.evaluate; полный повтор quality также включает А-9.
