# AI Candidate Scoring System

## Системные требования
* Установленный Docker Desktop.
* **Внимание для пользователей macOS (Apple Silicon):** В настройках Docker (Settings -> Resources) необходимо выделить минимум 8 GB оперативной памяти для корректной компиляции ML-зависимостей.

## Запуск
Откройте терминал в корневой директории проекта и выполните команду:

```bash
docker compose up --build -d
```

## Доступные адреса
* **Фронтенд:** http://localhost:3000
* **API (Swagger):** http://localhost:8000/docs

## Инструкция по работе с веб-интерфейсом

### 1. Подготовка данных
* **Загрузка собственных файлов:** В верхней панели выберите файлы резюме и вакансий через соответствующие поля выбора файлов. Загрузка и парсинг выполняются автоматически.
* **Генерация тестового датасета:** Нажмите кнопку **«🧪 Сгенерировать данные»**, чтобы наполнить базу синтетическими вакансиями и резюме (после генерации обновите страницу).
* **Очистка базы:** Кнопки **«🗑 Удалить резюме»** и **«🗑 Удалить вакансии»** полностью очищают соответствующие коллекции MongoDB.

### 2. Настройка и расчет скоринга
1. В блоке **«Вакансии»** выберите целевую вакансию из выпадающего списка.
2. При наличии требований к стеку появится блок **«Отметьте критические навыки (вес ×2)»**. Отметьте чекбоксами ключевые (must-have) технологии.
3. Нажмите кнопку **«Рассчитать скоринг»**.

### 3. Анализ рейтинга и карточки кандидата
* **Таблица лидеров:** В блоке **«Рейтинг кандидатов»** отображается ранжированный список соискателей с итоговым процентом соответствия.
* **Детальный просмотр:** Кликните по строке любого кандидата в таблице, чтобы открыть модальное окно:
  * **Оригинальный текст:** Кнопка **«📄 Посмотреть текст резюме»** разворачивает полный исходный текст документа.
  * **Обратная связь (HR Feedback):** Кнопки **«Релевантен»** / **«Нерелевантен»** сохраняют решение рекрутера в базу данных.

## Остановка
Для завершения работы контейнеров выполните:

```bash
docker compose down
```
